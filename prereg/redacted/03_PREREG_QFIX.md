# PREREG_QFIX — PBE-Net이 요건 Q(양자화 붕괴)에 답하게 만든다 (사용자 결정 10/16 "T/Q를 발견해 놓고 처리 못 하는 논문은 쓰지 않는다 → ㄱ")

작성 2026-10-16 00:5x, 노벨티 평가 세션 [id]. 측정 전 고정. 서버 gpu-server(3090×2), 총 GPU ≤20 h.

## 0. 현재 사실 (P3, 66 ckpt)
PBE-Net 18셀(6 ds × {w4_pt, a6, l50}) 중 11 붕괴(retention <0.8): w4 2/6, a6 4/6, l50 5/6. 라벨 없는 fp32–양자화 출력 일치도가 붕괴를 AUC .991로 판별.

## 1. 단계 A — 붕괴 귀속 (기존 ckpt 30개, 학습 없음, GPU ≤2 h)
- 구성요소 단위 양자화: {feature block, predictive skip(각 stage), boundary head, 입력 stem, 1×1 head} 각각 **하나만** w4 / a6 / l50 적용, 나머지 fp32. 지표: retention(Dice_q/Dice_fp32, val split), 라벨 없는 일치도(test 8장 Dice(fp32, q)).
- 추가 진단: 부품별 활성 범위(max|act|, 채널 간 스케일 비), 가중치 범위, dead 채널 비율 — 붕괴 부품과 상관을 Spearman으로.
- **가설 H_A(사전)**: 붕괴 셀의 retention 손실 중 ≥70%가 ≤2개 부품에서 난다(부품별 단독 양자화 손실의 합 대비). 통과 → 단계 B 표적 수정. 실패(손실이 고루 분산) → 단계 B는 전체 QAT만.
- 출력 `iso/s4/qfix/A_attribution.md` + json. 코드 sha 기입, 합성 역검증(인위적으로 한 부품에 노이즈를 넣은 ckpt로 귀속이 그 부품을 가리키는지).

## 2. 단계 B — 수정 도출 (LLM, 서버 0)
- B1 표적 수정 후보 ≤3(단계 A 결과에서만 도출): 예 — 해당 부품의 활성 범위 제약(학습 시 클리핑·PACT형), 채널별 양자화 스케일, 활성 함수 교체, 부품의 fp16 유지(혼합 정밀도 — 단 "fp32 유지"는 Q를 푼 것이 아니므로 가중치·활성 모두 양자화 대상인 설계만 인정).
- B2 기준 수정: 전체 QAT(교과서, 보정 데이터 = train split).
- G0′ 2회: PACT·LSQ·range-BN·DFQ/CLE·의료 분할 QAT·"PTQ-robust lightweight segmentation". 표적 수정이 같은 부품·같은 처방의 정확 선행이면 B1에서 제외(B2만 남으면 방법 기여 = 교과서로 정직하게 표기).
- 출력 `iso/s4/qfix/B_fix_design.md`: 수정 정의, 그것이 단계 A의 어느 사실에서 따라 나오는지(랩 규칙), 예상 비용.

## 3. 단계 C — 재학습·재평가 (GPU ≤16 h)
- 학습: 6 ds × 5 split, 프로토콜 v1 그대로(동일 seed·epoch·보조 손실), 수정 모델 1종(B1 1순위; B1이 없으면 B2). 보조로 B2도 같은 예산 안이면 1 ds·5 split만.
- 평가: Table 1 정확도(fp32)와 Q 프로토콜(w4_pt·a6·l50, retention·라벨 없는 일치도). 공식 test는 봉인(결과 1회).
- **성공 기준(사전)**: (i) retention ≥0.8인 셀 ≥16/18(현재 7/18), (ii) fp32 Dice가 v1 PBE-Net 대비 전 데이터셋에서 split 표준편차 안, (iii) 라벨 없는 판별기 AUC ≥.95 유지. (i)(ii)(iii) 전부 → "PBE-Net이 Q에 답한다" 채택, 기여 2 = 수정된 PBE-Net, 제목에 그 사실. (i)만 실패 → 부분(셀 수 보고), 기여 2는 "효율 + 부분 강건". (ii) 실패 → 정확도-강건성 트레이드오프로 보고, 주장 없음.
- 예측: H_A 통과 .5, B1 통과(선행 없음) .3, C 성공(B1 또는 B2) .7, B2만으로 성공 시 방법 중하(교과서) 명시.

## 4. 원고 반영 (단계 C 뒤)
- 서론 정식화 유지; 기여 2 = "Q에 답하는 PBE-Net(수정)", 구성요소 → 단계 A 사실 → 수정의 유도 문장(G-F5). 한계 절의 "압축 취약" 문장은 결과대로 갱신(해결/부분/미해결). Q 절에 수정 전후 표. 제목은 결과에 따라 사용자 결정.
